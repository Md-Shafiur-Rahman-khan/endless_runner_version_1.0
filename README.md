# endless_runner_version_1.0
# 🎮 Subway Surfers 3D — Classical Symphony Edition

An immersive, browser-based 3D endless runner game featuring railway tracks, obstacle avoidance, score tracking, gold coin collection, and dynamic audio. Run, jump, slide, and switch tracks to survive as long as possible!

## 🌐 Live Demo

**Play the game:** [https://hciprojectgame.vercel.app/](https://hciprojectgame.vercel.app/)

## ✨ Features

- **3D Endless Runner Gameplay** — Experience an endless subway-running challenge.
- **Track Switching** — Move between tracks to avoid obstacles.
- **Jump Mechanics** — Jump over barriers and other obstacles.
- **Slide Mechanics** — Roll under obstacles to keep running.
- **Touch Controls** — Supports swipe gestures for touchscreen devices.
- **Keyboard Controls** — Play using your keyboard.
- **Score System** — Track your score and running distance.
- **Gold Coin Collection** — Collect coins during gameplay.
- **Score Multiplier** — View your current score multiplier.
- **Best Score Tracking** — Track your all-time best score.
- **Dynamic Audio** — Experience spatial audio and classical orchestral elements.
- **Game Over Screen** — View your final score and collected coins.
- **Replay Option** — Start another run after game over.
- **Browser-Based Gameplay** — Play directly from the live website.

## 🕹️ Controls

| Action | Keyboard | Touch |
|---|---|---|
| Switch tracks left | `←` / `A` | Swipe left |
| Switch tracks right | `→` / `D` | Swipe right |
| Jump | `↑` / `W` / `Space` | Swipe up |
| Slide | `↓` / `S` | Swipe down |
| Start game | Click **RUN NOW!** | Tap the start button |
| Restart | Click **PLAY AGAIN** | Tap the replay button |

## 🎯 How to Play

1. Open the [live game](https://hciprojectgame.vercel.app/).
2. Click **RUN NOW!** to begin.
3. Switch between railway tracks to avoid obstacles.
4. Jump over barriers and slide under obstacles.
5. Collect gold coins and try to increase your score.
6. Run as far as possible without getting caught.
7. After game over, review your results and select **PLAY AGAIN**.
